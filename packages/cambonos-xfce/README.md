# cambonos-xfce

Metapaquete de la experiencia XFCE de CambonOS. Compone `cambonos-base`,
`cambonos-xfce-conf` y las aplicaciones generales seleccionadas: Mousepad, MPV, Atril,
Ristretto y Galculator.

LibreOffice Fresh y Hunspell son dependencias opcionales. La infraestructura Xorg,
Thunar, audio, red, Bluetooth, almacenamiento extraíble, miniaturas, credenciales,
`gnome-disk-utility`, `htop` y `nvtop` se proporcionan desde `cambonos-graphical-base`.

Este paquete no contiene archivos ni scripts de instalación y no sustituye todavía la
integración heredada del instalador o del perfil ISO; esa migración requiere cambios
coordinados en sus repositorios respectivos y validación de una ISO limpia.
