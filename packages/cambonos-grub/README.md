# cambonos-grub

Configuración y tema visual de GRUB para CambonOS.

## Funciones

- Tema gráfico, iconos de sistemas operativos y recursos de arranque.
- Configuración de multiboot mediante os-prober.
- Actualización del menú después de cambios de kernel.

## Dependencias

`bash`, `grub`, `os-prober`.
