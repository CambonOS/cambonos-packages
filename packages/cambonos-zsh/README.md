# cambonos-zsh

Configuración global de Zsh para ofrecer una experiencia interactiva coherente en CambonOS.

## Funciones

- Autocompletado, historial y atajos de teclado.
- Autosuggestions y resaltado de sintaxis.
- Cargador de fragmentos para integraciones de otros paquetes.
- Elevación de privilegios para operaciones de Pacman que modifican el sistema.

## Dependencias

`zsh`, `zsh-completions`, `zsh-autosuggestions`, `zsh-syntax-highlighting`, `cambonos-shell-prompt`, `util-linux`, `sudo`.
