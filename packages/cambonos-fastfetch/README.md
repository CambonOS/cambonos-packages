# cambonos-fastfetch

Perfil de Fastfetch con la identidad visual de CambonOS e integración en shells interactivos.

## Funciones

- Logotipo y configuración de Fastfetch.
- Los colores usan nombres ANSI y siguen la paleta activa del terminal.
- Integración automática con Bash y shells opcionales Zsh y Fish.

## Dependencias

`fastfetch`, `cambonos-release`, `bash`, `util-linux`.
