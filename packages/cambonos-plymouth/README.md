# cambonos-plymouth

Tema gráfico de arranque de CambonOS e integración con mkinitcpio.

## Funciones

- Tema Plymouth con fondo, iconos y barra de progreso.
- El logo y la barra escalan proporcionalmente a la resolución, tomando `1920x1080` como referencia.
- Integración con las imágenes initramfs.
- Selección del tema y actualización de presets existentes.

## Dependencias

`plymouth`, `mkinitcpio>=36`.
