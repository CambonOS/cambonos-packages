# cambonos-pacman

Configuración de los repositorios CambonOS y opciones adicionales de Pacman.

## Funciones

- Canales stable y testing.
- Verificación obligatoria de firmas.
- Integración reversible con la configuración de Pacman.
- Opciones visuales y de descarga propias de CambonOS.

## Dependencias

`bash`, `coreutils`, `diffutils`, `gawk`, `cambonos-keyring`.
