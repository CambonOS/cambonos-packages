# cambonos-keyring

Material público de confianza utilizado por Pacman para verificar los repositorios CambonOS.

## Funciones

- Certificado público de CambonOS.
- Información de confianza y revocación para Pacman.
- Inicialización de la confianza cuando el keyring de Pacman está disponible.

## Dependencias

`pacman`.
